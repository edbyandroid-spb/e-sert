# Генератор подарочных сертификатов: инструкция

## Что это
Страница, которая рисует картинку сертификата (JPG 2160×2700) по вашим данным. Картинку можно отправить в Telegram. Страница ничего не запоминает и никуда не отправляет: все данные остаются в вашем браузере.

## Файлы
Все файлы лежат в **одной папке**. Расположение менять нельзя: `settings.js`, `background.jpg` и папка `themes` должны лежать рядом с `index.html`.

| Файл | Для чего | Менять? |
|---|---|---|
| `index.html` | Сама страница-генератор (внутри шрифты и вся логика) | Нет |
| `settings.js` | **Все настройки**: имя, телефон, ник, префикс номера, срок, список тем, имя файла фона | Да, в Блокноте |
| `settings_backup.js` | Копия исходных настроек, нужна для сброса | Нет, храните как есть |
| `background.jpg` | Общий фон всех сертификатов (иллюстрация Леры) | Можно заменить |
| `themes/main.png` | Картинка темы «Основной» (камни, свеча, орхидея) | Можно заменить |
| `themes/mom.png` | Картинка темы «Для мамы» (розы, свеча, чашка) | Можно заменить |
| `themes/HNY.png` | Картинка темы «Новый год» (шары, ель, свеча) | Можно заменить |
| `ИНСТРУКЦИЯ.md` | Этот файл | Нет |

Файлы тем называются по теме: `mom` (для мамы), `HNY` (Новый год), `main` (основная). Название файла должно совпадать с тем, что написано в `settings.js` в строке `file:`.

## Как открыть
1. Загрузите папку на GitHub Pages: создайте **публичный** репозиторий, перетащите в него все файлы **вместе с папкой `themes`** (Add file → Upload files). Затем Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. Через 1–2 минуты страница откроется по ссылке `https://ваш-логин.github.io/название-репозитория/`. Сохраните её в закладки (на телефоне — «Добавить на главный экран»).

**Открытие файла прямо из папки** (двойной клик по `index.html` на компьютере или в проводнике телефона): страница откроется и покажет сертификат, но **сохранить картинку браузер не даст**. Это защита браузера: когда картинки лежат отдельными файлами, он блокирует их использование. Нужна интернет-ссылка, как выше. Если понадобится работа без интернета, это можно сделать отдельным вариантом (картинки встроены в страницу).

## Как делать сертификат
1. Откройте страницу. Выберите тему в списке (по умолчанию «Основной»).
2. Впишите «Для кого» и «От кого» так, как должно стоять после «Для:» и «От:», например «Марии», «Анны».
3. Выберите вид массажа (или оставьте «Выберет получатель при записи»). Проверьте дату продажи.
4. Впишите две цифры номера. Номер берите из таблицы учёта (первая строка без даты). Страница номера не проверяет и не меняет.
5. Нажмите «Сохранить файл». На телефоне после этого появится кнопка «Отправить…».
6. В Telegram отправляйте файл «как файл» (скрепка → «Файл»), иначе картинка сожмётся.
7. «Скопировать подпись для Telegram» копирует текст подписи со ссылкой на запись.
8. «Скопировать строку для таблицы» копирует данные для таблицы. В таблице щёлкните ячейку «№» этой же строки и нажмите Ctrl+V.

## Как добавить свою тему
1. Подготовьте PNG **с настоящей прозрачностью**. Квадратная или слегка вытянутая картинка шириной 700–1000 пикселей подойдёт лучше всего. Назовите латиницей без пробелов, например `8march.png`, и положите в папку `themes`.
2. Откройте `settings.js`. В списке `THEMES` скопируйте любой блок `{ ... }`, вставьте ниже (между блоками нужна запятая) и измените `name`, `file`, `sub`, `wish1`, `wish2`.
3. Сохраните файл и загрузите на GitHub поверх старого (и новый PNG в `themes`). Обновите страницу с Ctrl+F5.

Внимание: многие картинки из нейросетей «с прозрачным фоном» на самом деле содержат нарисованную серо-белую шахматку, а не прозрачность. У присланных `mom` и `HNY` было так (это были JPEG), я вырезал фон автоматически. Если у вашей картинки в шахматку, фон нужно вырезать до загрузки.

## Как поменять фон целиком
Замените файл `background.jpg` новой **вертикальной** картинкой с пропорциями 4:5 (например, 1620×2025 пикселей), оставив то же имя. Если имя другое, впишите его в `settings.js` в строке `background:`. Рамки, линии и надписи рисуются поверх фона, их цвет не меняется, поэтому фон лучше брать светлым. Картинки тем лежат поверх фона в левом нижнем углу.

## Где хранятся настройки и как их сбросить
- Все настройки в одном файле: **`settings.js`**. В браузере ничего не хранится.
- Сброс: удалите `settings.js`, скопируйте `settings_backup.js` и переименуйте копию в `settings.js`. Загрузите на GitHub поверх.
- Если после правки страница пишет «Не удалось прочитать файл settings.js», значит, при редактировании потерялась кавычка или запятая: сделайте сброс.
- Записи журнала и темы из прошлых версий генератора (они хранились в браузере) больше не используются, их можно игнорировать.
